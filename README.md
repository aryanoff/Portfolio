# Aryan Singh Rajpoot — Portfolio

A personal portfolio website showcasing my work as a full-stack web developer, UI/UX designer, music producer, and digital content creator.

## Live Site

https://github.com/aryanoff/Portfolio

## Tech Stack

- HTML5 — Semantic, accessible markup
- CSS3 — Vanilla CSS with custom properties, Grid, Flexbox, animations
- JavaScript — Vanilla ES6+, DOM manipulation, IntersectionObserver
- Web3Forms — Contact form submission
- Cloudinary — Image hosting
